# [실습 과제] 농산물 가격 정보 시각화 대시보드

## 1. 실습 목표

KAMIS ( https://www.kamis.or.kr/ )에서 제공하는 농산물 가격 데이터를 활용하여 Streamlit 기반의 간단한 농산물 가격 정보 시각화 대시보드를 구현한다.

Pandas로 Excel 데이터를 처리하고, Plotly로 가격 변화 그래프를 생성한 후 Streamlit 화면에 표시한다.

## 2. 제공 데이터

다음 5개의 Excel 파일을 사용한다.

- `딸기_가격정보.xlsx`
- `배추_가격정보.xlsx`
- `사과_가격정보.xlsx`
- `수박_가격정보.xlsx`
- `쌀_가격정보.xlsx`

각 파일에는 해당 농산물의 최근 5개월 가격 정보가 포함되어 있다.

## 3. 구현 조건

### (1) Streamlit 화면 구성

Streamlit을 이용하여 다음과 같은 대시보드 화면을 구성한다.

- 대시보드 제목 표시
- 농산물 선택 메뉴
- 평균 가격 표시
- 가격 변화 그래프 표시
- 가격 데이터 표 표시

### (2) 농산물 선택

`selectbox`를 이용하여 다음 5개 농산물 중 하나를 선택할 수 있도록 구현한다.

```text
딸기
배추
사과
수박
쌀
```

선택한 농산물에 해당하는 Excel 파일의 데이터를 불러온다.

### (3) 평균 가격 계산

선택한 농산물의 가격 데이터를 이용하여 평균 가격을 계산하고 Streamlit 화면에 표시한다.

예:

```text
평균 가격
8,250원
```

### (4) 가격 변화 시각화

Plotly를 이용하여 최근 5개월간의 가격 변화를 Line Chart로 시각화한다.

- X축: 날짜 또는 월
- Y축: 가격
- 그래프 제목: 선택한 농산물의 가격 변화

생성한 Plotly 그래프는 `st.plotly_chart()`를 이용하여 Streamlit 화면에 출력한다.

### (5) 가격 데이터 표시

선택한 농산물의 원본 데이터를 Streamlit의 데이터프레임으로 표시한다.

## 4. 최종 화면 예시

```text
========================================
       농산물 가격 정보 대시보드
========================================

농산물 선택
[ 딸기 ▼ ]

평균 가격
8,250원

----------------------------------------

        월별 농산물 가격 변화

        [ Plotly Line Chart ]

----------------------------------------

        가격 데이터

        [ DataFrame ]
========================================
```

## 5. 선택 과제

기본 기능을 완성한 후 시간이 남는 경우 다음 기능 중 하나를 추가한다.

- 5개 농산물의 평균 가격을 Bar Chart로 비교
- 최고 가격과 최저 가격 표시
- 전월 대비 가격 변화율 계산
- 분석 기간 선택 기능 추가

## 6. 실행 환경

필요한 라이브러리를 설치한다.

```bash
pip install pandas openpyxl plotly streamlit
```

프로그램을 다음 명령으로 실행한다.

```bash
streamlit run app.py
```
