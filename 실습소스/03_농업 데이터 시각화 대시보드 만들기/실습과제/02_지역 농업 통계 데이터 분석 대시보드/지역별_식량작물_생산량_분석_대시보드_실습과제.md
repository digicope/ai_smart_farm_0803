# [실습 과제] 지역별 식량작물 생산량 분석 대시보드

## 1. 실습 목표

2016~2025년 지역별 식량작물 생산량 데이터를 활용하여 우리나라 지역별 식량작물 생산 현황과 연도별 변화를 분석한다.

Pandas를 이용하여 데이터를 처리하고, Plotly를 이용하여 시각화한 후, Streamlit을 이용하여 인터랙티브한 농업 통계 대시보드를 구현한다.

## 2. 제공 데이터

제공된 CSV 파일을 사용한다.

```text
식량작물_생산량_정곡__20260808172102.csv
```

분석 대상 기간은 2016~2025년으로 한다.

2026년 데이터는 분석에서 제외한다.

데이터에는 지역별 식량작물의 면적과 생산량 정보가 포함되어 있다.

주요 식량작물은 다음과 같다.

- 미곡
- 맥류
- 잡곡
- 두류
- 서류

## 3. 구현할 대시보드

### (1) 지역 선택

Streamlit의 `selectbox`를 이용하여 분석할 지역을 선택한다.

예:

```text
지역 선택
[ 전라남도 ▼ ]
```

### (2) 식량작물 선택

다음 식량작물 중 하나를 선택할 수 있도록 구현한다.

```text
[ 미곡 ▼ ]
```

선택 항목:

```text
미곡
맥류
잡곡
두류
서류
```

### (3) 연도별 생산량 변화

선택한 지역과 작물의 2016~2025년 생산량 변화를 Plotly Line Chart로 시각화한다.

- X축: 연도
- Y축: 생산량
- 제목: 지역 및 작물의 연도별 생산량 변화

### (4) 지역별 생산량 비교

선택한 연도의 지역별 생산량을 Plotly Bar Chart로 시각화한다.

예:

```text
2025년 미곡 생산량

전남   ███████████████████
충남   ███████████████
전북   █████████████
경북   ███████████
경남   ████████
...
```

사용자가 분석 연도를 선택할 수 있도록 구현한다.

```text
연도 선택
[ 2025 ▼ ]
```

### (5) 핵심 통계 표시

선택한 지역과 작물에 대해 다음 정보를 표시한다.

- 선택 연도의 생산량
- 10년 평균 생산량
- 10년간 최대 생산량

예:

```text
┌────────────┬────────────┬────────────┐
│ 2025 생산량 │ 10년 평균  │ 최대 생산량 │
│ XXX,XXX톤  │ XXX,XXX톤  │ XXX,XXX톤  │
└────────────┴────────────┴────────────┘
```

## 5. 선택 과제

기본 기능을 완성한 경우 다음 기능 중 하나를 추가한다.

### 선택 과제 1. 생산량 증감률

2016년과 2025년의 생산량을 비교하여 10년간 생산량 증감률을 계산한다.

```text
생산량 증감률(%)
= (2025년 생산량 - 2016년 생산량)
  / 2016년 생산량 × 100
```

### 선택 과제 2. 식량작물별 비교

특정 지역의 미곡, 맥류, 잡곡, 두류, 서류 생산량을 Bar Chart로 비교한다.

### 선택 과제 3. 지역별 생산량 순위

선택한 연도의 생산량을 기준으로 지역별 순위를 표시한다.

예:

```text
1위  전라남도
2위  충청남도
3위  전라북도
...
```

## 6. 구현 조건

다음 라이브러리를 사용한다.

```python
import pandas as pd
import plotly.express as px
import streamlit as st
```

Plotly 그래프를 Streamlit 화면에 출력할 때는 다음과 같은 방식을 사용한다.

```python
st.plotly_chart(fig)
```

프로그램은 다음 명령으로 실행한다.

```bash
streamlit run app.py
```
