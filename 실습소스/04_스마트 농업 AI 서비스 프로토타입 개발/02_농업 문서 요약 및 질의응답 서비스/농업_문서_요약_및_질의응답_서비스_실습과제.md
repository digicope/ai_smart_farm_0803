# [실습 과제] 농업 문서 요약 및 질의응답 서비스 (RAG + FAISS)

## 1. 실습 목표

농촌진흥청([https://www.nongsaro.go.kr/](https://www.nongsaro.go.kr/)) 농업기술길잡이 등 PDF 문서를 기반으로  
**RAG(Retrieval-Augmented Generation)** 와 **FAISS** 벡터 검색을 활용한  
문서 요약·질의응답 서비스를 구현한다.

사용자가 작물 재배 관련 질문을 하면  
관련 문서 조각을 검색한 뒤, LLM이 근거 기반으로 답변·요약한다.

> 본 실습의 핵심은 **문서 임베딩 → FAISS 검색 → LLM 생성** 파이프라인이다.  
> Streamlit으로 실행 가능한 UI를 구성한다.

## 2. 선수 학습

다음 내용을 학습한 후 진행한다.

- OpenAI Chat Completions / Embeddings API
- 텍스트 청킹(Chunking) 개념
- 벡터 유사도 검색과 FAISS
- RAG 기본 흐름
- Streamlit 기본 UI

## 3. 제공 자료

같은 폴더의 PDF 문서를 사용한다.

```text
농업기술길잡이5_사과재배.PDF
농업기술길잡이28_고구마.PDF
농업기술길잡이40_딸기.PDF
농업기술길잡이105_참외.PDF
23 상추_저화질_단면.pdf
29 토마토_저화질_단면.pdf
5 고추 최종파일_단면.pdf
수박_단면.pdf
```

- 문서 주제: 사과, 고구마, 딸기, 참외, 상추, 토마토, 고추, 수박 등 재배 기술
- 일부 PDF는 페이지 수가 많아(200~370p) 실습 시 **페이지 제한**을 두는 것을 권장한다.



## 4. 구현할 기능



### (1) PDF 로드 및 청킹

선택한 PDF에서 텍스트를 추출하고 청크로 분할한다.

```text
입력: PDF 파일 경로, (선택) 최대 페이지 수
처리:
  1) PDF 페이지별 텍스트 추출
  2) 일정 길이로 분할 (예: chunk_size=800, overlap=150)
  3) 메타데이터 부여 (source, page)
출력: Document 리스트 (page_content + metadata)
```

권장 파라미터:


| 항목                | 권장값        |
| ----------------- | ---------- |
| `chunk_size`      | 600 ~ 1000 |
| `chunk_overlap`   | 100 ~ 200  |
| `max_pages` (실습용) | 20 ~ 50    |




### (2) 임베딩 및 FAISS 인덱스 구축

OpenAI Embeddings로 벡터를 만들고 FAISS에 저장한다.

```text
1. 청크 텍스트 → embedding 벡터 변환
2. FAISS 인덱스에 저장
3. (권장) 로컬 폴더에 인덱스 저장/로드
```

핵심 개념:

```text
질문 임베딩 ↔ 문서 청크 임베딩 유사도 검색 (cosine / L2)
```



### (3) RAG 질의응답

다음 흐름으로 질의응답을 구현한다.

```text
1. 사용자 질문 입력
2. 질문을 임베딩하여 FAISS에서 Top-K 청크 검색
3. 검색된 청크를 컨텍스트로 LLM에 전달
4. 근거 기반 답변 생성
5. (권장) 출처(파일명, 페이지) 함께 표시
```

프롬프트 가이드:

```text
- 컨텍스트에 있는 내용만으로 답한다
- 없으면 "문서에서 확인되지 않습니다"라고 말한다
- 가능하면 출처를 언급한다
```



### (4) 문서 요약

다음 중 하나 이상을 구현한다.

#### 방식 A. 주제 요약 (권장)

```text
주제(또는 질문) 입력
→ FAISS로 관련 청크 검색
→ 검색 결과만 요약
```

예: `"딸기 정식 시기와 주의사항"`

#### 방식 B. 선택 문서 요약

```text
특정 PDF 선택
→ 앞부분 청크(또는 샘플 청크)를 모아 요약
```



### (5) Streamlit UI

Streamlit으로 다음 화면을 구성한다.

- 제목: `농업 문서 요약 및 질의응답 서비스`
- 사이드바
  - PDF 다중 선택
  - 최대 페이지 수
  - Top-K
  - 인덱스 생성 버튼
- 메인
  - 탭1: 질의응답
  - 탭2: 문서 요약
  - (권장) 검색된 근거 청크 표시



## 5. 시스템 흐름도

```text

    ▼

    │

```



## 6. 테스트 질문 예시

인덱싱 후 다음 질문으로 RAG가 동작하는지 확인한다.


| 질문                | 기대 동작                |
| ----------------- | -------------------- |
| 딸기 정식 시기와 주의점은?   | 딸기 관련 청크 검색 후 답변     |
| 고구마 저장 방법은?       | 고구마 문서에서 저장 관련 내용 인용 |
| 사과 병해충 방제 방법을 알려줘 | 사과 문서 기반 방제 안내       |
| 참외 재배에 적합한 토성은?   | 참외 문서 기반 답변          |
| 우주선은 어떻게 만드나요?    | 문서에 없음 → 근거 부족 안내    |


요약 테스트 예:


| 입력                   | 기대 동작        |
| -------------------- | ------------ |
| 주제: 토마토 육묘 관리        | 관련 청크만 모아 요약 |
| 문서: 농업기술길잡이40_딸기.PDF | 선택 문서 핵심 요약  |

## 8. 구현 조건



### 필수

1. 현재 폴더의 PDF를 최소 2개 이상 인덱싱할 수 있어야 한다.
2. OpenAI Embeddings + FAISS 검색을 사용한다.
3. RAG 방식으로 질의응답을 구현한다. (문서 없이 LLM만 답하지 말 것)
4. 문서 요약 기능을 제공한다.
5. Streamlit으로 실행 가능해야 한다.
6. 검색된 근거(출처)를 화면에 표시한다.



### 권장

- FAISS 인덱스를 로컬에 저장/재사용한다.
- `max_pages`로 실습 시간을 조절한다.
- 시스템 프롬프트에 "농업 기술 문서 기반 답변" 역할을 명시한다.
- 컨텍스트에 없는 내용은 추측하지 않는다.



## 9. 선택 과제

기본 기능을 완성한 경우 다음 중 하나를 추가한다.

### 선택 과제 1. 인덱스 영속화

```text
faiss_index/ 폴더에 저장
앱 재실행 시 기존 인덱스 로드
```



### 선택 과제 2. 유사도 점수 표시

검색된 각 청크의 거리/유사도 점수를 UI에 표시한다.

### 선택 과제 3. 멀티 문서 비교 요약

두 작물 문서를 선택해  
"정식 조건", "병해충", "저장" 등 항목별로 비교 요약을 생성한다.

## 10. 실행 환경

필요한 라이브러리를 설치한다.

```bash
pip install -r requirements.txt
```

`.env` 파일에 API 키를 설정한다.

```text
OPENAI_API_KEY=sk-...
```

프로그램을 다음 명령으로 실행한다.

```bash
streamlit run app.py
```
