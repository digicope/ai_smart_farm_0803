────────────────────────────────────────
2. 과제 목표
────────────────────────────────────────

동일한 RAG 시스템에서 다양한 검색 전략을 적용하고,
검색 결과와 답변 품질을 비교한다.

학습 포인트
  1) 동일 코퍼스·동일 질문에서 검색 전략만 교체했을 때 결과 차이를 확인한다.
  2) HyDE / Multi-Query / Self-Query / Rerank / 히스토리 압축의 적용 시점과 장단점을 이해한다.
  3) 연도 메타데이터가 있는 문서에서 Self-Query 필터 효과를 확인한다.


────────────────────────────────────────
3. 과제 내용
────────────────────────────────────────

[1] 데이터 준비

  - PDF 문서를 로드하여 Chunking을 수행한다.
  - 연차보고서의 연도 정보(year)를 메타데이터로 저장한다.
    (파일명에서 연도 추출, source/page 메타데이터도 함께 저장 권장)
  - Chroma Vector DB(로컬 Persistent)를 구축한다.
  - 임베딩 모델과 생성 모델은 자유롭게 선택하되, 전략 비교 시에는 동일하게 고정한다.
    (예시: text-embedding-3-small, gpt-4o-mini)


[2] 검색 전략 구현

  다음 검색 전략을 각각 구현한다.

  (1) Basic Retrieval (Naive)
      - 질문을 그대로 임베딩하여 similarity search 수행

  (2) HyDE
      - LLM으로 가상(답변형) 문서를 생성한 뒤, 그 문서로 벡터 검색
      - 가상 문서는 검색용으로만 사용하고, 최종 답변 근거는 실제 검색 문서만 사용

  (3) Multi-Query Retriever
      - 질문을 여러 관점으로 재작성한 뒤 검색 결과를 합집합(unique union)

  (4) Self-Query Retriever
      - 자연어 질문에서 검색어와 메타데이터 필터(예: year=2024)를 분리하여 검색

  (5) Reranking
      - Cross-Encoder 또는 Cohere Rerank 중 하나 이상 구현
      - 1차에서 후보를 넓게 가져온 뒤(예: BASE_K), 재점수화하여 상위 TOP_N만 사용


[3] 대화 히스토리 관리

  - 멀티턴 대화를 구현한다.
  - 대화가 길어질 경우 이전 대화를 요약하여 컨텍스트를 관리한다.
    (예: 오래된 턴 요약 + 최근 턴 원문 유지, 필요 시 문서 토큰 예산도 분리)


[4] 성능 비교

  동일한 질문에 대해 각 검색 전략을 적용하여 다음 항목을 비교한다.

  - 검색 결과 (출처, 연도, 페이지 등)
  - 답변 품질 (동일 생성 프롬프트로 grounded 답변 비교)
  - 검색 정확도 (정성 비교 또는 연도 필터 적중·출처 적합 여부 등으로 분석)
  - 실행 속도 (전략별 소요시간 측정)


────────────────────────────────────────
4. 구현 조건 / 제약
────────────────────────────────────────

  - Vector DB: Chroma DB 사용
  - 모든 전략이 같은 벡터스토어·같은 TOP_N·같은 답변 생성 체인을 사용하도록 한다.
    (차이는 Retriever/검색 전략만)
  - 답변은 검색된 문맥에만 근거하도록 grounded 프롬프트를 사용한다.
  - Cohere Rerank는 API 키가 없으면 생략 가능 (Cross-Encoder만으로도 인정)


────────────────────────────────────────
5. 구현 후 동작 테스트 내용
────────────────────────────────────────

  1) 인덱싱 과정 (로딩 → 청킹 → Chroma 저장) 코드 및 실행 결과
  2) 전략별 검색/답변 실행 결과
  3) 동일 질문·복수 질문에 대한 비교표 (출처, 연도, 소요시간, 답변 요약)
  4) 멀티턴 + 히스토리 압축 전/후 토큰·답변 비교
  5) 정리: 상황별 추천 전략과 선택 이유
