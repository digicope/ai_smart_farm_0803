# 공공데이터포털 기상청 단기·중기예보 조회서비스 API 발급 방법

## 1. 개요

공공데이터포털에서는 **기상청_단기예보 조회서비스**와 **기상청_중기예보 조회서비스**를 별도의 Open API로 제공한다. 따라서 두 서비스를 모두 사용하려면 각각 활용신청을 진행한다. 공공데이터포털에서도 두 API가 별도 서비스로 등록되어 있다.

- 공공데이터포털: https://www.data.go.kr/
- 단기예보: 기상청_단기예보 조회서비스
- 중기예보: 기상청_중기예보 조회서비스

---

## 2. 공통 회원가입

1. 공공데이터포털에 접속한다.
2. 회원가입 후 로그인한다.
3. 검색창에서 원하는 API를 검색한다.
4. 해당 API 상세 페이지에서 **활용신청**을 선택한다.
5. 활용목적을 입력하고 신청한다.
6. 마이페이지에서 발급된 인증키를 확인한다.

> 두 API는 별도 서비스이므로 **각각 활용신청하여 사용한다.**

---

# 3. 단기예보 API 발급

## API 이름

**기상청_단기예보 조회서비스**

초단기실황, 초단기예보, 단기예보 등을 제공하며 단기예보는 글피까지의 상세한 기상정보를 제공한다. 

### 신청 방법

공공데이터포털 검색:

```text
기상청_단기예보 조회서비스
```

검색 결과에서 해당 API를 선택한다.

```text
상세 페이지
   ↓
활용신청
   ↓
신청 완료
   ↓
마이페이지
   ↓
인증키 확인
```

### 인증키 저장

단기예보 전용 키로 관리한다.

```text
KMA_SHORT_TERM_KEY=단기예보_API_인증키
```

# 4. 중기예보 API 발급

## API 이름

**기상청_중기예보 조회서비스**

https://www.data.go.kr/data/15059468/openapi.do

단기예보 이후 **향후 11일까지**의 기상전망, 최고·최저기온, 강수확률 등의 정보를 제공한다. 일 2회 발표되는 서비스이다. 

### 신청 방법

공공데이터포털 검색:

```text
기상청_중기예보 조회서비스
```

검색 결과에서 해당 API를 선택한다.

```text
상세 페이지
   ↓
활용신청
   ↓
신청 완료
   ↓
마이페이지
   ↓
인증키 확인
```

### 인증키 저장

중기예보 전용 키로 관리한다.

```text
KMA_MID_TERM_KEY=중기예보_API_인증키
```

---

# 5. API 키를 반드시 구별해서 관리

두 API를 모두 사용하는 경우 다음과 같이 **환경변수 이름을 분리**하는 것을 권장한다.

```text
KMA_SHORT_TERM_KEY=단기예보_인증키
KMA_MID_TERM_KEY=중기예보_인증키
```

Python에서는 다음과 같이 사용한다.

```python
import os

SHORT_TERM_KEY = os.getenv("KMA_SHORT_TERM_KEY")
MID_TERM_KEY = os.getenv("KMA_MID_TERM_KEY")
```

## Agent Tool도 분리

```python

def get_short_term_weather(nx, ny):

    pass

def get_mid_term_weather(reg_id):

    pass
```

# 6. 스마트 농업 Agent 활용

```text
                    사용자
                      │
                      ▼
                 AI Agent
                      │
             ┌────────┴────────┐
             ▼                 ▼
       단기예보 Tool       중기예보 Tool
             │                 │
      KMA_SHORT_TERM_KEY   KMA_MID_TERM_KEY
             │                 │
             ▼                 ▼
          1~3일 상세        최대 11일 전망
             │                 │
             └────────┬────────┘
                      ▼
                   LLM 분석
                      ▼
              농업 의사결정
```

예:

> "앞으로 10일간 날씨를 분석해서 토마토 농작업 계획을 세워줘."

Agent가 단기예보와 중기예보 Tool을 각각 호출하여 종합 분석하도록 구성할 수 있다.

# 7. 핵심 정리

| 구분 | 단기예보 | 중기예보 |
|---|---|---|
| API | 기상청_단기예보 조회서비스 | 기상청_중기예보 조회서비스 |
| 활용신청 | 별도 신청 | 별도 신청 |
| 인증키 | **단기예보 키** | **중기예보 키** |
| 환경변수 | `KMA_SHORT_TERM_KEY` | `KMA_MID_TERM_KEY` |
| 주요 용도 | 단기간 상세 예보 | 최대 11일 전망 |
| Agent Tool | `get_short_term_weather()` | `get_mid_term_weather()` |

### 최종 관리

```text
.env

KMA_SHORT_TERM_KEY=단기예보_API키
KMA_MID_TERM_KEY=중기예보_API키
```

**단기예보 키와 중기예보 키를 혼동하지 않고 별도로 관리하는 것이 핵심이다.**
